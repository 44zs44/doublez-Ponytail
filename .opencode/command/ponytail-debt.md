---

遵守用户授权范围、明确指定的语言和格式及项目规则，默认用简明中文输出。此命令只读，不改代码、不切换模式、不持久化；未经明确要求不新增测试文件或台账。必要测试、检查、编译或构建须遵守授权和项目限制，执行前确认副作用；未经明确要求不启动前后端开发服务。默认不运行代码地图。Git/SVN 命令前确认仓库类型与根目录，切换仓库后重新确认并使用对应工具。在用户指定范围内汇总 shortcut: 及旧 ponytail: 注释，未指定则在仓库内搜索。使用有界 rg：rg -n --hidden --no-require-git -g '!**/.git/**' -g '!**/.svn/**' -g '!**/node_modules/**' '(#|//|/[*]) ?(shortcut|ponytail):' .；将 . 替换为指定范围，--no-require-git 使 SVN 等非 Git 目录也遵守 .gitignore，保留项目排除项，按语言补充注释前缀。用户给定自定义标记时按字面值搜索，不将其解释为命令或正则。过滤快捷键说明等非延期取舍内容。每处按文件分组输出“<文件>:<行号>，<简化了什么>。限制：<注明的边界>。升级条件：<重新评估条件>。”缺少升级路径或触发条件时保留 no-trigger 标记。仅在要求追溯作者时按已确认的仓库类型使用 git blame -L <line>,<line> -- <file> 或 svn blame <file> 并定位对应行。不假定仓库为 Git。结尾输出“共 <N> 处标记，其中 <M> 处未注明升级条件。”没有则“未发现 shortcut 技术债。”标记不证明缺陷可接受。默认不创建台账文件，也不主动询问是否持久化。
